# 平台口径

## 1. 三个平台的差别

| | 小红书 | 视频号 | 抖音 |
| --- | --- | --- | --- |
| 用户状态 | 主动搜，带问题来 | 社交关系链 + 推荐 | 被系统推，注意力短 |
| 竞争格局 | 素人平权、门槛低 | 托底机制、规则相对公平 | 职业团队在场，要预算和编导 |
| 内容形态 | 图文/视频都行，双列信息流 | 视频为主，圈层传播 | 视频为主，单列全屏 |
| 生死线 | **封面 + 标题** | 开头 + 社交推荐 | **前 2 秒** |
| 适合 | 高客单、长决策、强信任 | 复购、私域放大 | 曝光型内容、快消 |
| 常见失败 | 有收藏没咨询 | 起量慢 | 有播放没客户 |

**共同点**：三条链路都是「曝光 → 点击 → 看完 → 动作」。差别只在每一环的通过难度和承接方式。

---

## 2. 内容形态的翻译规则

同一个选题，三个平台的写法不一样，**文案可以共用，节奏不能共用**。

| | 抖音 | 小红书 |
| --- | --- | --- |
| 钩子怎么落地 | 前 2 秒必须是画面 + 声音的刺激 | 封面 + 标题的文字承诺 |
| 铺垫能多长 | 几乎不能铺垫 | 可以，用户有搜索意图 |
| 最好用的人性 | 嗔（不服、对立、被落下） | 贪／痴（"我也能拿到这个结果"） |
| 成交链路 | 最长，要直播或私域接 | 最短，看完就去主页 |

一条内容在抖音爆了但没咨询，通常不是内容不行，是**承接没做**：主页没说清"我是谁、卖什么"。

---

## 3. 导流的合规底线

平台规则会变，以下是保守做法，不是官方条文：

- 不在正文和口播里直接念微信号、手机号
- 不用谐音、拆字、符号拼写绕过审核
- 不承诺"加我就送""私聊领全套"这类强诱导
- 需要留资时，把动作放在**评论区**或**主页简介**，用平台允许的表达（关键词、私信、主页链接）
- 医疗、金融、教育、减肥这几类，效果承诺和绝对化用语的风险最高，一律改第一人称记录口径

**判断标准**：如果这句话需要你"想个办法绕过检测"，那就不要写。

## 4. 哪些是经验值，哪些是规则

| 说法 | 性质 | 怎么用 |
| --- | --- | --- |
| 互动权重里关注 > 评论 > 点赞 | 经验口径，平台未完整公开 | 当假设，用自己数据验证 |
| 发布后 2 小时内互动影响更大 | 运营经验 | 可以试，别当铁律 |
| 某平台不适合个人冷启动 | 资源分配判断 | 是优先级，不是禁令 |
| 完播率低于某数值就该改开头 | 伪精确 | 用你自己的基线，不用别人的数字 |
| 封面标题决定点击 | 稳定规律 | 可以直接用 |

任何"必爆""稳上热门""三天起号"的说法都不要采信。这套方法能保证的是**结构不犯错**，不是保证结果。
