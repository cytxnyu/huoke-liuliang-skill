# 四张卡（复制即用）

每张卡都是填空。填不满的空格就是还缺的材料，不要用形容词糊过去。

---

## 卡 1：定位卡（只做一次，做完存成 `profile.md` 反复用）

```markdown
# 定位卡

**能力**：（我会什么，具体到能交付的动作）
**人群**：（越窄越好：年龄段 + 身份 + 处境）
**紧急需求**：（他现在立刻要解决的痛，带触发场景）
**产品形式**：（1v1 咨询 / 陪跑 / 定制 / 小班，交付周期多久）
**结果**：（用户拿到什么，可验证）
**价格**：（现在收多少，上限能到多少）
**平台**：（主战场 + 分发）

## 一句话定位
我有什么【】，能帮【】，解决【】，通过【】，让他们获得【】。

## 值钱三校验
- [ ] 我能解决（别人替代不了的点是什么）
- [ ] 客户付得起（这类人月收入量级/付费习惯）
- [ ] 问题等不起（拖下去会损失什么）

## 优势三抽屉
- 工作经历：
- 成长经历：
- 兴趣技能：
```

## 卡 2：选题卡（一次出 10 张）

```markdown
## 选题卡 N

**痛点原话**：（客户说的原句，带引号，不改写）
**人群**：（这批人在哪，怎么找到他们）
**人性**：贪 / 嗔 / 痴（选一个，说明为什么）
**公式**：A（痛点前置） / B（结果前置）
**泛钩子**：（让人想看的那版）
**付费钩子**：（筛出想买的那版）
**素材需求**：（需要什么截图、对比图、案例、数据）
**48 小时能拍吗**：能 / 不能（不能就写卡在哪）
```

排序规则：先按**付费意图**（这条内容能不能直接带来咨询）排，再按**素材可得性**（手边有没有东西拍）排。

## 卡 3：钩子卡（一个选题出 5 个）

```markdown

| 1 |      | 数字/对比/身份/反常识 | 泛/付费 |      |          |      |
| 2 |      |      |      |      |          |      |
| 3 |      |      |      |      |          |      |
| 4 |      |      |      |      |          |      |
| 5 |      |      |      |      |          |      |

**缺项检查**：数字 [ ] 反常识 [ ] 付费 [ ]
**秒数换算**：4.2–4.8 字/秒；3 秒 ≤ 14 字
**承诺兑现**：视频里用什么兑现这句话
```

## 卡 5：归因卡（一次只填一个结论）

```markdown
## 数据归因

**数据**：曝光 __ ｜点击 __ ｜点击率 __% ｜平均观看 __s / 时长 __s ｜完播率 __% ｜赞 __ ｜藏 __ ｜评 __ ｜咨询 __ ｜成交 __
**基线**（近 30 天同形态中位数）：点击率 __% ｜完播率 __%

**卡点层**：曝光 / 点击 / 看完 / 咨询 / 成交（只选一个）
**判断依据**：
**这一版只改**：
**下一版具体改法**：
**对照方式**：（同一时间窗、同形态内容对比）
```

没有基线时，第一行结论必须是"缺基线，先发 5–7 条收集"，不许直接下判断。
