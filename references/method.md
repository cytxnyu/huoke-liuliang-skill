# 方法论内核

这套流程的前提：**账号不是作品集，是一条成交路径。**

```
陌生人 → 看内容 → 进主页 → 付费
```

每条内容只负责其中一环。赚不到钱通常卡在三处：没想清楚卖什么就开始发、什么人都想吸引、只盯流量不设计路径。

播放量不是终点。要看的是「曝光 → 点击 → 看完 → 咨询 → 成交」这条链路，哪一环断了改哪一环。

---

## 1. 定位：五维交集

**我的能力 × 客户人群 × 紧急需求 × 产品形式 → 获得的结果**

填空题（必须能一口气填满，填不满说明定位没成）：

> 我有什么【能力】，能帮【哪类细分人群】解决【什么痛点】，通过【什么交付方式】，让他们获得【什么结果】。

范例：

> 会美学搭配 → 30+、身高 170 以下、偏瘦偏胖、频繁相亲被拒的男性 → 明天要见聊了 30 天的女生 → 1v1 形象顾问私教（1–2 万／社交场景版 3–5 万）→ 半年内穿搭 + 相亲全流程，避免被厌恶、冷场。

### 能不能卖贵：三条同时成立才行

| 条件 | 含义 |
| --- | --- |
| 你能解决 | 专业度极高、可替代性低，命中核心痛点 |
| 客户付得起 | 目标人群有真实支付能力 |
| 问题等不起 | 刚需、痛点深，拖延有明显损失 |

用户只为**看得懂、信得过**的结果付钱，不为"你很专业"付钱。

### 优势从哪来：三个抽屉

- **工作经历**：岗位／公司／行业（运营、商务 BD、超一线大厂、AI、传统行业）
- **成长经历**：高光／至暗／转折（考研、考编、原生家庭、生病、被骗）
- **兴趣技能**：爱好／才艺／长期投入（养宠、美妆、国学、瑜伽、语言）

经历不是用来卖惨，是用来让用户明白**你为什么懂这个问题**。

## 2. 变现模式：普通人从"卖服务"起步

| 模式 | 本质 | 适合谁 |
| --- | --- | --- |
| 广告 | 把注意力卖给品牌 | 已有粉丝基础 |
| 带货 | 帮用户做购买决策拿佣金 | 有选品／供应链 |
| 知识产品 | 资料／课程／训练营 | 有体系化方法 |
| **卖服务** | **咨询／陪跑／定制交付** | **冷启动首选：客单价上限高、交付可控** |

先有产品和价格，再谈内容。顺序反了，内容全是自嗨。

## 3. 平台：搜索型 vs 推荐型

| | 搜索型（小红书） | 混合型（视频号） | 推荐型（抖音） |
| --- | --- | --- | --- |
| 用户状态 | 主动搜，带着问题来 | 社交关系链 + 推荐 | 被系统推，注意力短 |
| 竞争 | 素人平权、门槛低 | 托底机制、规则相对公平 | 职业团队在场，要预算 |
| 内容要求 | 封面标题定生死，内容要给答案 | 适合长期关系与复购 | 前 2 秒定生死，强刺激 |
| 适合 | 高客单、长决策、强信任 | 复购、私域放大 | 曝光型、快消 |

**选择顺序**：先在搜索型平台验证"这个问题有人愿意为答案付费"，再往推荐型平台放大。反过来做（先赌爆款再想卖什么）就是典型的"只盯流量、不设计路径"。

> 抖音并非不能做，但它是注意力生意：爆了也可能只是"看过"。承接链路最长，必须有私域或直播接住。

## 4. 推荐漏斗：四层，每层一个零件

| 层 | 决定因素 | 失败了改哪 |
| --- | --- | --- |
| 能不能被推荐 | 内容合规 + 主题明确 | 选题、账号标签 |
| 曝光后点不点 | 封面 + 标题 | 封面、标题 |
| 点进来完不完 | 开头承接标题 | 前 3–8 秒 |
| 有没有更深动作 | 曝光到成交的链路 | 留资、主页、承接 |

## 5. 五格脚本公式

- **公式 A（痛点前置）**：痛点 → 误区 → 结果 → 解决思路 → 利益留资
- **公式 B（结果前置）**：结果 → 痛点 → 误区／人设案例 → 解决思路 → 利益留资

两支的差别只在开头先抛痛点还是先抛结果。选择依据：

- 痛点**极其具体且普遍**（人人都踩过）→ 用 A
- 结果**有强证据**（前后对比、真实数字、可验证案例）→ 用 B

第五格"利益留资"是整条内容的目的：**内容不直接卖，而是让人主动来找你**。缺这一格，播放量等于 0。

反例：以"喜欢的朋友可以留言点关注"结尾——那是泛钩子，换来热闹，换不来钱。

## 6. 钩子：先分类型，再选写法

### 两种钩子，目的不同

| 泛人群钩子 | 付费人群钩子 |
| --- | --- |
| 让人看、点赞、收藏 | 把真想买单的人筛出来 |
| "英硕回国简历被刷，简历究竟怎么写啊" | "我帮双非拿到 G5 的 3 个选校逻辑" |
| "孩子写作业拖拉真的很难，可以一起讨论" | "整理的一套测评，帮 200 个娃提了 30 分" |
| 带来热闹 | 带来钱 |

判断方法：把钩子念给一个陌生人听，如果他的反应是"哦，然后呢"，那是泛钩子；如果他问"这个怎么弄"或"多少钱"，那是付费钩子。

### 四种写法

| 写法 | 作用 | 例 |
| --- | --- | --- |
| 带数字 | 具体、可信、可比 | 3 天／5 个方法／第 8 步 |
| 搞对比 | 制造冲击 | 改之前 vs 改之后 |
| 亮身份 | 精准命中一类人 | 一年制硕士回国求职 |
| 反常识 | 打破认知、引讨论 | 简历别写自我评价 |

**一个选题写 3–5 个钩子分开发，让数据替你选。** 不要一次只赌一个。

### 秒数换算

口播语速约 4.2–4.8 字／秒，按 3 秒 12–14 字卡上限。超了就砍，不靠加速。

## 7. 痛点：90% 来自客户原话

| 来源 | 价值 | 怎么用 |
| --- | --- | --- |
| 客户问过的问题 | 最高 | 抄原句，不改写，一句一条存库 |
| 同行观点 | 中 | 看他们在讲什么、哪些有互动 |
| 同行评论区高赞 | 高 | 高赞＝大家真的在意，直接当选题 |
| 知乎／贴吧／长文 | 中高 | 长文里藏着最完整的纠结链条 |

原话和总结的区别：原话带情境和第一人称，总结只剩抽象名词。**抽象名词不能当痛点。**

## 8. 爆款的底层：人性

| 字 | 表现 | 内容里怎么用 |
| --- | --- | --- |
| 贪 | 想要更多、更快、更省事 | 给捷径、给省时间的步骤 |
| 嗔 | 不服、焦虑、怕被落下 | 给对比、给"你正在被超过"的紧迫 |
| 痴 | 迷恋某个结果、某个人、某种身份 | 给"我就是你要成为的样子"的证据 |

选题过一遍三字筛：一个都不命中，就别浪费这条视频。
注意：**人性决定会不会火，结构决定火完有没有用。** 只靠情绪、没有承接的内容，涨的是看客。

## 9. 账号分工：信任和转化分仓

| 主号／专家号 | 素人号 |
| --- | --- |
| 讲方法、讲看法、拆案例 | 负责把人带过来，评论区是主战场 |
| 让人觉得"这人值得付费" | 用小号去问、素人号来答 |
| **尽量不直接导流**（易被限，也掉价） | 话术像朋友推荐，不能有打广告的口气 |

**铁律：主号让人信你，素人号把人带来。**
专家人设和销售动作混在同一个号里，结果是人设崩、信任没。

承接的常见路径：内容里的委婉钩子 → 评论区互动 → 私信 → 私域。每一跳都要有明确的下一步，且符合平台规则。

## 10. 归因：五条，一次只改一条

见 SKILL.md §4 的表。三条补充规则：

1. **用基线不用绝对值。** 拿近 30 天同形态内容的中位数当基线，低于 20% 以上才算异常。
2. **一次只改一层。** 同时改三处，数据回来了你也不知道为什么。
3. **先怀疑内容，再怀疑平台。** 把浏览量低全部归因成"限流"，是最省事也最没用的解释。

## 11. 七个坑（发布前自查）

1. 定位不清，不知道要吸引谁
2. 每天想到什么发什么，没有主线
3. 每天更新，播放量只有几十
4. 有流量，没有客户咨询
5. 产品定价不合理，越交付越累
6. 花钱投流，不知道怎么算账
7. 想导私域，操作不当有风险

## 12. 口径边界

这套方法来自实践经验，不是平台官方规则。以下几条要当**假设**用，用自己的数据验证：

- 互动权重、时间衰减之类的评分口径，平台从未完整公开
- "发布后两小时内集中撬互动"属于运营经验，不是确定机制
- "某平台不适合个人冷启动"是资源分配判断，不是内容无效
- 任何"必爆""稳涨"的说法都不要采信

以及一条硬边界：**效果承诺、绝对化用语、医疗与金融类夸大表述，会带来限流和合规风险。** 内容里只写第一人称的真实经历。
